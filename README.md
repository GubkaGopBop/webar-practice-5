# Практическая работа 5 — Three.js WebAR

**Запуск:** https://gubkagopbop.github.io/webar-practice-5/

Сцена с офисным креслом и барным табуретом. Доступны смена цвета обивки, поворот на ±15° и автовращение. На совместимом устройстве объект размещается на поверхности через WebXR hit-test, а HTML-интерфейс остаётся доступным через DOM Overlay.

Технологии: HTML, CSS, JavaScript, Three.js 0.186.0, WebXR API. Используются PBR-материалы MeshStandardMaterial и процедурная HDR environment map с PMREM. Модели процедурные; glTF и фотографический HDR-файл не используются.

## Структура

`docs/index.html` — страница запуска. `docs/src` — классы App, ARController, ObjectController, ModelFactory, Environment и UIController. `docs/vendor` — локальная копия Three.js и лицензия MIT.

GitHub Pages публикует папку `/docs` из ветки `main`. Все ресурсы используют относительные ссылки. На ПК нажмите «Посмотреть в 3D». Для AR нужен совместимый телефон и браузер; наличие HTTPS само по себе не гарантирует поддержку AR. Полный мобильный тест проводится отдельно.

Матрица размещения хранится в anchor, вращение — в pivot. Поэтому смена модели не сбрасывает положение в комнате. При замене освобождаются геометрии и материалы старого объекта.
